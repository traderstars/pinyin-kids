# 小小普通话乐园

面向 5 岁儿童的普通话拼音、普通话识字与粤语识字启蒙工具。目前包含完整拼音目录的 63 个学习内容、100 个普通话生活常用字和对应的 100 个粤语识字内容，共自动编排为 90 节小课。

## 运行

可以直接双击打开 `index.html`。如浏览器限制本地语音，可在本目录运行：

```sh
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

教学语音使用 `zh-CN-XiaoxiaoNeural` 普通话女声和 `zh-HK-HiuGaaiNeural` 香港粤语女声预生成在 `audio/` 中，孩子使用时不需要联网。浏览器系统语音只作为音频文件加载失败时的备用方案。

课程完成记录与家长语音审核记录保存在浏览器本机。首页的“检查课程语音”可进入审核页，逐条标记合格或需要重做。

工具会按每个拼音或汉字分别记录正确、错误和连续掌握次数，并按 1、2、4、7、14、30 天安排间隔复习。首页显示今日建议，家长进度页分别汇总三条课程线。所有记录只保存在当前浏览器，不会提交到网站或 GitHub。

项目已经支持安装到 iPad 主屏幕。部署到 HTTPS 网址后，在 iPad Safari 中打开，选择“共享 → 添加到主屏幕”，并启用“作为 Web App 打开”。首次完整加载后，课程页面和全部音频可离线使用。

如修改了教学口令，可重新生成语音：

```sh
.venv/bin/python scripts/generate_audio.py
```
